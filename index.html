Frequently Asked Questions

What is the CSS grid-template-rows trick?

It's a clever technique to animate elements to an unknown auto height. By transitioning grid-template-rows from 0fr to 1fr, the browser can smoothly animate the expansion without needing hardcoded heights or JavaScript.

Does this require any JavaScript?

Nope! By using the native HTML name attribute on the <details> elements, the browser automatically handles closing the other open items in the group just like radio buttons.

Is it accessible?

Yes, because it relies completely on semantic HTML. Keyboard navigation, screen readers, and focus states work perfectly out of the box without any extra ARIA configuration.
